# プライバシーポリシー

mochiOS Team（以下「運営者」）は、mochiOSおよび関連サービスの提供、保守、改善、セキュリティ確保のため、必要な範囲で利用者に関する情報を取り扱います。
運営者は、利用者のプライバシーを尊重し、情報の取得を必要最小限に抑えるとともに、取得する情報、利用目的および利用者による選択を明確にします。

## 適用範囲

本プライバシーポリシーは、以下に適用されます。

- mochiOS
- mochiOS公式サイト
- mochiOS AppStore
- Developer Console
- mochiOSが提供するAPI
- その他運営者が提供する関連サービス

## 取得する情報

### アカウントおよびサービス利用に関する情報

mochiOS関連サービスでは、必要に応じて以下の情報を取得する場合があります。

- GitHub OAuthを通じて取得するGitHub ID、ユーザー名、表示名、アバターURL
- 開発者ID
- ログイン状態およびセッションCookie
- 登録された公開鍵
- Bundle ID
- アプリ情報およびリリース情報
- アプリパッケージおよび電子署名
- 証明書の発行または申請に関する情報
- IPアドレス、User-Agent、アクセス日時
- サービスの操作ログ
- 問い合わせ時に利用者が送信した内容

### mochiOSの診断情報

mochiOSでは、品質改善、安定性の評価、障害解析および利用状況の統計的な把握を目的として、利用者の同意を得た場合に限り診断情報を送信します。

診断情報の送信は任意です。同意しない場合でも、mochiOSの利用およびアップデートは可能です。

#### 基本診断情報

基本診断への同意を得た場合、以下の情報を取得することがあります。

- ランダムに生成された固定端末ID
- OSバージョン
- ビルド番号
- アーキテクチャ
- インストール日
- 最終アクティブ日
- 正常起動の成否
- 前回の終了状態
- 送信が許可されたクラッシュの件数
- 送信が許可されたクラッシュのコンポーネント名およびエラーコード
- RAM容量帯
- mochiPCであるかどうかの区分
- アップデート後の起動、更新失敗およびロールバックに関する結果

インストール日、最終アクティブ日および診断イベントの発生日は、原則として日単位で扱います。
クラッシュに関する情報は、基本診断への同意に加え、個別のクラッシュについて送信が許可されている場合に限ります。
詳細なCPU・GPU型番および個別のハードウェアモデルは収集しません。

#### 追加の同意が必要な情報

以下の情報は、基本診断とは別に利用者の同意を得た場合に限り取得します。

- よく使用しているアプリに関する利用統計
- 国・地域に関する情報

アプリの利用統計には、アプリ内の入力内容、閲覧内容および開いたファイルの情報を含めません。

国・地域の情報を取得する場合も、緯度経度、住所および移動履歴は収集しません。

IPアドレスを利用して、追加の同意なしに国・地域の情報を補完することはありません。

### 固定端末ID

固定端末IDは、診断報告を継続的に関連付け、重複計上を防止するために使用します。

固定端末IDはランダムに生成し、氏名、アカウント情報、MACアドレス、ハードウェアのシリアル番号その他の固有情報から生成しません。

通常のアップデートまたはダウングレードでは、同じ固定端末IDを維持します。

固定端末IDは、利用者が基本診断に同意している場合に限りサーバーへ送信します。

固定端末IDを含む診断情報は、継続的に同一端末からの報告を関連付けることができるため、完全に匿名な情報としては扱いません。

診断情報をGitHubアカウントその他の利用者アカウントと関連付ける機能は設けません。また、更新確認時のIPアドレスを固定端末IDと関連付けて利用状況を追跡することはありません。

### クラッシュ情報

mochiOSの標準アプリおよびシステムサービスがクラッシュした場合、当該クラッシュについて診断情報を送信するか利用者に確認します。

カーネルパニックについては、再起動後に送信の確認を行います。

クラッシュ情報の送信には、基本診断への同意と、対象クラッシュについての個別の許可の両方が必要です。

利用者が送信を拒否した場合、当該クラッシュに関する以下の情報は送信しません。

- クラッシュレポート
- クラッシュ件数への加算
- コンポーネント名
- エラーコード
- クラッシュの発生を示す状態情報
- 当該クラッシュを推測できる更新結果その他の情報

拒否されたクラッシュについて、後日の集計、再送処理その他の方法で情報を送信することもありません。

また、以下の情報はクラッシュ診断の収集対象としません。

- スタックトレース
- メモリダンプ
- レジスタダンプ
- メモリ内容を含む診断データ
- 無条件に収集される自由形式のログ本文やpanicメッセージ

サードパーティアプリのクラッシュ情報は、mochiOSの標準診断機能による収集対象に含めません。

## 診断情報への同意と撤回

診断情報の送信は、利用者の明示的な同意に基づいて行います。

利用者が同意しない場合、診断データ、利用統計、固定端末IDおよびアップデート結果を送信しません。

同意しなかったという事実を診断イベントとして送信することもありません。

同意前に発生した診断情報を、後から同意を得たことを理由として自動的に遡って送信することはありません。

利用者は診断情報の送信に関する同意を撤回できます。同意を撤回した場合、新たな診断情報の送信および端末内に残る未送信データの送信を停止します。

基本診断および追加診断への同意は区別して管理します。

ただし、アップデートの確認、ファイルの取得その他オンラインサービスの提供に必要な通信は、診断情報の送信とは区別します。

これらの通信を、利用者の同意なくアクティブ端末数や利用状況の統計に流用することはありません。

## 利用目的

取得した情報は、以下の目的で利用します。

- ログインおよび本人確認
- 開発者アカウントの管理
- アプリの登録、審査および配信
- 証明書の発行および管理
- mochiOSのインストール状況および利用状況の統計的な把握
- OSバージョンおよびビルドごとの利用状況の分析
- mochiOSおよび関連サービスの品質、性能および安定性の改善
- 起動失敗、クラッシュ、更新失敗その他の障害の調査
- 不正利用、権利侵害およびセキュリティ事故の防止
- サービスの保守および障害対応
- 利用者からの問い合わせへの対応

診断情報については、利用者が同意した範囲を超えて利用しません。

取得した情報を、本プライバシーポリシーに記載した目的と無関係な目的で利用することはありません。

## 第三者提供

運営者は、法令に基づく場合、または利用者もしくは第三者の権利、安全もしくはサービスの安全性を保護するために必要な場合など、法令上認められる場合を除き、取得した個人情報を本人の同意なく第三者に提供しません。

ただし、サービスの運営に必要な範囲で、ホスティング、CDN、認証その他のサービスを提供する事業者に情報の取扱いを委託する場合があります。

運営者は、委託先に対して、取り扱う情報の性質およびリスクに応じた適切な管理を求めます。

## 外部サービス

mochiOS関連サービスでは、機能の提供に外部サービスを利用する場合があります。

GitHub OAuthを使用する場合、GitHub上で利用者が認可した範囲の情報のみを取得します。

外部サービス上で取り扱われる情報については、各サービス提供者の規約およびプライバシーポリシーが適用される場合があります。

## Cookie

mochiOS関連サービスでは、ログイン状態の維持、セキュリティ確保その他サービスの提供に必要な目的でCookieを使用する場合があります。

Cookieによって取得した情報を、診断情報への同意を迂回して端末の利用状況を追跡する目的では使用しません。

## 情報の保存

取得した情報は、利用目的の達成に必要な期間に限り保持します。

診断情報については、固定端末IDを含む情報、クラッシュ報告、活動履歴、更新結果および集計済みデータを区別して管理します。

固定端末IDに関連付けられた情報を、単なる集計結果と同様に無期限に保存することは前提としません。

利用目的を達成し、保持する必要がなくなった情報については、合理的な期間内に削除または個々の利用者もしくは端末を識別できない形式に加工します。

ただし、法令上の義務、セキュリティ対応、不正利用の調査その他正当な理由がある場合は、必要な期間保持する場合があります。

## 情報の削除

利用者は、運営者に対して、アカウント情報その他利用者に関連するデータの削除を依頼できます。

診断情報の送信に関する同意を撤回した場合、それ以降の診断情報の送信を停止します。

既に受信した診断情報については、利用者または対象端末との対応を確認できる範囲で、削除の可否および方法を確認します。

ただし、法令上の義務、セキュリティ対応、不正利用の調査その他正当な理由により、直ちに削除できない場合があります。

個別の端末との対応関係が失われた集計情報については、特定の利用者または端末から送信された情報を識別できず、個別に削除できない場合があります。

## 情報の管理

運営者は、取得した情報について、不正アクセス、漏えい、滅失、毀損その他の事故を防止するため、情報の性質およびリスクに応じた合理的な安全管理措置を講じます。

情報へのアクセスは、業務上必要な権限を有するメンバーに制限します。

診断情報は、アカウント情報および認証情報と不必要に関連付けないよう管理します。

## プライバシーポリシーの変更

本プライバシーポリシーは、法令、サービス内容または情報の取扱い方法の変更等に応じて改定する場合があります。

利用者に重大な影響を与える変更を行う場合は、mochiOS公式サイト、公式コミュニティその他適切な方法で告知します。
また、新たな種類の診断情報を収集する場合、または既存の同意範囲を超える情報収集を行う場合には、必要に応じて改めて利用者の同意を取得します。
