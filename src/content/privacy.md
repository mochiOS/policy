プライバシーポリシー

mochiOS運営者は、mochiOSおよびmochiOS関連サービスの提供、保守、改善、セキュリティ確保のため、必要な範囲で利用者に関する情報を取り扱います。

適用範囲

本プライバシーポリシーは、以下に適用されます。

mochiOS

mochiOS公式サイト

mochiOS AppStore

Developer Console

mochiOSが提供するAPI

その他mochiOS運営者が提供する関連サービス

取得する情報

アカウントおよびサービス利用に関する情報

mochiOS関連サービスでは、必要に応じて以下の情報を取得する場合があります。

GitHub OAuthを通じて取得するGitHub ID、ユーザー名、表示名、アバターURL

開発者ID

ログイン状態

セッションCookie

登録された公開鍵

Bundle ID

アプリ情報およびリリース情報

アプリパッケージ

電子署名

証明書の発行または申請に関する情報

IPアドレス

User-Agent

アクセス日時

操作ログ

問い合わせ時に利用者が送信した内容

mochiOSの利用統計

mochiOSでは、利用状況の把握、品質改善および障害解析のため、以下の情報を取得する場合があります。

ランダムに生成されたインストール識別子

OSバージョン

ビルド番号

アーキテクチャ

インストール日時

最終アクティブ日時

正常起動の成否

前回の終了状態

クラッシュ件数

クラッシュしたコンポーネント名

RAM容量帯

インストール識別子には、MACアドレス、ディスクのシリアル番号、CPUの識別情報その他のハードウェア固有情報を使用しません。

利用統計は、氏名、メールアドレス、GitHubアカウントその他の個人を直接識別する情報とは紐付けません。

また、利用統計の送信元IPアドレスを、インストール識別子として使用しません。

ただし、通信の提供、安全性の確保、不正利用の防止等のため、サーバー、CDNその他のインフラストラクチャ上でIPアドレス等の通信情報が一時的に記録される場合があります。

利用目的

取得した情報は、以下の目的で利用します。

ログインおよび本人確認

開発者アカウントの管理

アプリの登録、審査および配信

証明書の発行および管理

mochiOSのインストール数および利用状況の集計

OSバージョンごとの利用状況の把握

mochiOSおよび関連サービスの品質、性能および安定性の改善

起動失敗、クラッシュその他の障害の調査

不正利用、権利侵害およびセキュリティ事故の防止

サービスの保守および障害対応

利用者からの問い合わせへの対応

取得した情報を、本プライバシーポリシーに記載した目的と無関係な目的で利用することはありません。

第三者提供

法令に基づく場合、または利用者もしくは第三者の権利、安全もしくはサービスの安全性を保護するために必要な場合を除き、取得した情報を第三者に提供しません。

ただし、サービスの運営に必要な範囲で、ホスティング、CDN、認証その他のサービスを提供する事業者に情報の取扱いを委託する場合があります。

外部サービス

mochiOS関連サービスでは、機能の提供に外部サービスを利用する場合があります。

GitHub OAuthを使用する場合、GitHub上で利用者が認可した範囲の情報のみを取得します。

外部サービス上で取り扱われる情報については、各サービス提供者の規約およびプライバシーポリシーが適用される場合があります。

Cookie

mochiOS関連サービスでは、ログイン状態の維持、セキュリティ確保その他サービスの提供に必要な目的でCookieを使用する場合があります。

情報の保存

取得した情報は、利用目的の達成に必要な期間に限り保持します。

利用目的を達成し、保持する必要がなくなった情報については、合理的な期間内に削除または個々の利用者もしくはインストールを識別できない形式に加工します。

ただし、法令上の義務、セキュリティ対応、不正利用の調査その他正当な理由がある場合は、必要な期間保持する場合があります。

情報の削除

利用者は、運営者に対して、アカウント情報その他利用者に関連するデータの削除を依頼できます。

ただし、法令上の義務、セキュリティ対応、不正利用の調査その他正当な理由により、直ちに削除できない場合があります。

個人を直接識別する情報と紐付けられていない利用統計については、特定の利用者から送信された情報を識別できず、個別に削除できない場合があります。

情報の管理

mochiOS運営者は、取得した情報について、不正アクセス、漏えい、滅失、毀損その他の事故を防止するため、情報の性質およびリスクに応じた合理的な安全管理措置を講じます。

プライバシーポリシーの変更

本プライバシーポリシーは、法令、サービス内容または情報の取扱い方法の変更等に応じて改定する場合があります。

利用者に重大な影響を与える変更を行う場合は、mochiOS公式サイト、公式コミュニティその他適切な方法で告知します。

問い合わせ

プライバシーに関する問い合わせは、以下までご連絡ください。

security@mochios.org
